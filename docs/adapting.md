# 企业微信改版后怎么适配

WeComDroid 尽量不依赖企业微信的控件 ID（它们是混淆过的，每个版本都会变），而是靠这些比较稳定的特征：

| 动作 | 靠什么认 |
|---|---|
| 打开某个群 | 企业微信通知自带的点击意图；打开后核对**屏幕顶部 15%** 有一行字等于群名（允许「群名(人数)」） |
| 找输入框 | 屏幕上**恰好一个**可见的可编辑控件 |
| 点发送 | 文字恰好是「发送」的控件（本身不可点就往上找可点的父控件） |
| 确认发出 | 输入框里的字被清空 |
| 引用 | 原消息气泡的规范化文字完全相等 → 长按 → 文字恰好是「引用」的菜单项 |
| 发文件 | 企业微信的分享入口 →「最近聊天」或搜索里名字完全相等且唯一的会话 → 确认弹窗里再核对群名 |

认不出来时一律**停手并上报**，不会猜着点。

## 新版本不兼容时

1. 服务器上看 `wecomdroid status` 和日志，找到失败的指令和错误码（如 `no_input`、`no_send_button`、`picker_not_shown`）。
   失败时手机会把当时的屏幕文字一起传回来，存在 `data/dumps/*-error_screen-*.json`。
2. 在 App 里打开**侦察模式**，在机器人手机上把出问题的那几个界面手动走一遍，然后关掉侦察模式。
   每个界面的完整控件树会出现在 `data/dumps/*-dump-*.json`。
3. 开 issue，写上企业微信版本号、手机型号和安卓版本，附上 dump 文件。
   **dump 里可能有群聊内容，发之前请删掉敏感信息。**

需要改代码的地方基本都在 `android/app/src/main/java/.../BotAccessibilityService.kt`。
