# 手机设置

## 准备

- 一台**闲置**安卓手机：Android 8.0 及以上，**不支持鸿蒙**。建议 Android 11+，后台保活更稳。不要用主力机。
- 一个**专用的企业微信员工账号**给机器人用：
  - 同一个账号只能在一台手机上登录，用你自己的号会把你挤下线；
  - 万一被限制，影响的只是这个号。
- 手机一直**插着充电器**，连着稳定的 WiFi。

## 企业微信

1. 安装企业微信，登录机器人账号。
2. **关闭自动更新**（应用商店里设置）。企业微信大改版可能需要适配，别让它半夜自己升级。
3. 设置 → 新消息通知：打开通知，**显示消息详情**。通知是机器人发现新消息的唯一入口。
4. 记下机器人在群里显示的名字，填进服务器的 `SPAREDROID_BOT_NAME`，必须一字不差。
   企业微信的通知**不一定**带「[有人@我]」标记，很多时候只能靠名字认出 @。

## SpareDroid App

1. 从 [Releases](https://github.com/Tonieeie/sparedroid/releases) 下载 APK。
   数据线连不上电脑也没关系，用微信「文件传输助手」发到手机上安装就行。
2. 打开 App，依次点：
   - **① 通知使用权** → 允许 SpareDroid
   - **② 无障碍** → 已安装的服务 → SpareDroid → 打开
   - **③ 关闭省电限制**
3. 手机系统设置里，允许 SpareDroid **自启动 / 后台运行**（各品牌叫法不同：小米「自启动」、OPPO/vivo「后台耗电管理」、三星「不受限制」）。
4. 在服务器上运行 `sparedroid config`，把打印的那一行发到手机上，复制，在 App 里点 **「从剪贴板导入配置」**。
5. 状态面板四个 ✅，「最近心跳成功」有时间，就连上了。

## 屏幕与锁屏

填字、点按钮这类操作需要屏幕亮着。屏幕黑着时，无障碍服务**读得到**界面，但**填不了字**
（真机上就是这样：能认出消息，回复却失败）。

从 0.2.1 起不用一直亮屏：每次要操作界面前，App 会自己点亮屏幕，做完再放手，之后按系统设置熄屏。
只需要做一件事：

- **锁屏方式设为「无」**。设了密码或滑动解锁的话，屏幕点亮后停在锁屏界面，无障碍服务解不开，
  动作会失败，错误码 `screen_locked`。

亮度调到最低就行。只收消息不需要亮屏，通知监听在熄屏时也能工作。
想更稳一点，也可以在开发者选项里打开「充电时不锁屏 / 充电时屏幕不休眠」（设置 → 关于手机 →
连续点「版本号」7 次开启开发者模式）。

## 常见问题

**状态面板里「通知使用权」显示已授权但没连上**
安卓的老毛病，常见于重装 App 后。App 每分钟会自动请求重连；不行就到通知使用权里把 SpareDroid **关掉再打开**，或重启手机。服务器会在恢复时通知你。

**重装 App 后机器人回复失败（`no_route`）**
机器人是通过「点通知进群」来打开群的，这个入口只存在内存里。重装或重启后，要等那个群再来一条消息才能回复。发文件不受影响。

**@ 了机器人没反应**
按顺序检查：服务器 `sparedroid status` 有没有心跳 → 群名在不在 `SPAREDROID_CHATS` 里 → `SPAREDROID_BOT_NAME` 和群里显示的是否一致 → App 里通知监听是否连着。
